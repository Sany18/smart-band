# voice-bridge — голос з браслета → Claude

Міст на Mac між модифікованим Mi Fitness (див. [`../mi-fitness-mod/voice-hook`](../mi-fitness-mod/voice-hook))
і Claude. Телефон шле записане браслетом аудіо, міст розпізнає мову
локально (whisper.cpp), передає текст у `claude -p` (Claude Code в headless-режимі,
авторизація — ваша підписка, під якою залогінений CLI) і повертає коротку відповідь
для екрана браслета.

```
Band 9 Pro ──BLE, Opus 16 kHz──▶ Mi Fitness (WatchVoiceHook) ──Tailscale──▶ bridge.py
                                                                         ├─ whisper-cli  (STT, локально)
   ◀── текст відповіді (n21: ASR / speak) ◀──────────────────────────────└─ claude -p   (агент)
```

## Запуск (Mac, служба launchd)

Міст працює на цьому Mac (`x2`), бо тут підключений inbox MCP — доступ до чатів і листів.

```bash
brew install whisper-cpp
mkdir -p ~/.cache/whisper && curl -L -o ~/.cache/whisper/ggml-large-v3-turbo-q5_0.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin
```

`.env` (не в git) — створюється один раз:

```
BRIDGE_TOKEN=<випадковий секрет, той самий у watchvoice.properties на телефоні>
BRIDGE_HOST=<tailscale-ip-of-mac>        # Tailscale-адреса Mac
BRIDGE_PORT=8787
STT_BACKEND=whisper-cli
STT_LANGS=uk,en                   # російська не розпізнається ніколи
CLAUDE_MODEL=haiku
CLAUDE_EXTRA_ARGS="--allowedTools mcp__inbox WebFetch(domain:wttr.in)"   # читати повідомлення і погоду
CLAUDE_CWD=/Users/you             # де працює агент
BRIDGE_KEEP_AUDIO=~/allProjs/smart-band/voice-bridge/recordings   # опційно: зберігати WAV
```

```bash
./install-mac.sh             # встановити/перевстановити службу (стартує при вході, перезапускається)
./install-mac.sh uninstall   # прибрати
launchctl kickstart -k gui/$(id -u)/com.watchvoice.bridge   # перезапуск після зміни .env/коду
tail -f ~/Library/Logs/voice-bridge.log                      # журнал
```

`run.sh` завантажує `.env` і прибирає `ANTHROPIC_API_KEY` із середовища: з ним `claude -p`
перейшов би з підписки на оплату за API.

### Linux (X1) — запасний варіант

`./deploy.sh x1` ставить міст як `systemd --user`-службу з `STT_BACKEND=faster-whisper`
(у venv). На X1 потрібен робочий вхід Claude (`claude setup-token` →
`CLAUDE_CODE_OAUTH_TOKEN` у `.env` на X1), а inbox MCP там немає. Зараз служба на X1
вимкнена (`systemctl --user disable --now voice-bridge`).

## Швидкість і черга

- Погода — одним `WebFetch` до wttr.in (так вказано в системному промпті): ~10 с замість
  18–30 с з веб-пошуком, яких браслет не дочікувався.
- Новий `/text` зупиняє `claude -p`, що ще працює над попереднім запитом; той отримує
  `409 superseded`. На голосовому асистенті актуальний лише останній запит.

## Мова

Дозволені лише українська й англійська (`STT_LANGS`, перша — запасна):

- одна мова → розпізнавання примусово нею;
- whisper спершу визначає мову (+~0,8 с), але на тихому мікрофоні браслета це ненадійно:
  українську він називає `ru` з p до 0.79 (а російська давала 0.71), а також `es`/`ja`.
  Тому відмова за визначенням вимкнена (`RU_REJECT_P=1.01`), англійська береться лише при
  `en` з p ≥ `EN_MIN_P` (0.5), усе інше розпізнається українською;
- **російська ловиться після розпізнавання**: якщо в тексті є типові російські слова
  (`что, чей, зачем, какой, сейчас, спасибо, и` … — `RUSSIAN_WORDS`), фраза відкидається.
  Російська, примусово розпізнана як українська, дає суміш («Та, за чей ти працюєш?»), у якій
  такі слова лишаються;
- `ru` викидається зі списку, навіть якщо його вписати;
- результат з суто російськими літерами (`ы э ъ ё`) або типовими галюцинаціями whisper
  (`Продолжение следует`, `Субтитры…`) відкидається — браслет покаже «Не розчув, повторіть»;
- системний промпт забороняє Claude відповідати російською.

## Налаштування

| Змінна | За замовчуванням | Що робить |
|---|---|---|
| `STT_BACKEND` | `whisper-cli` | `whisper-cli` (Mac) або `faster-whisper` (Linux CPU) |
| `STT_LANGS` | `uk` | дозволені мови через кому |
| `RU_REJECT_P` | `1.01` (вимкнено) | з якої впевненості визначення `ru` фраза відкидається |
| `EN_MIN_P` | `0.5` | з якої впевненості розпізнавати англійською |
| `LANG_REJECT_REPLY` | «Розпізнаю лише українську та англійську» | що показати при відмові |
| `WHISPER_MODEL` | `~/.cache/whisper/ggml-large-v3-turbo-q5_0.bin` | модель для whisper-cli |
| `FW_MODEL` / `FW_COMPUTE` | `large-v3-turbo` / `int8` | модель для faster-whisper |
| `CLAUDE_MODEL` | `haiku` | модель агента (порожнє = за замовчуванням CLI) |
| `CLAUDE_EXTRA_ARGS` | — | напр. `--allowedTools mcp__inbox` |
| `CLAUDE_TIMEOUT` | 180 | секунд на відповідь агента |
| `SESSION_IDLE` | 600 | після стількох секунд тиші починається нова розмова |
| `REPLY_MAX` | 280 | браслет обрізає текст на 300 символах |

Ендпоінти (усі з заголовком `X-Token`): `GET /health`, `POST /stt`, `POST /text`,
`POST /voice`, `POST /reset`. Див. docstring у `bridge.py`.

## Безпека

- Слухає лише Tailscale-інтерфейс і вимагає токен.
- `claude -p` за замовчуванням **не має дозволів** на запис файлів і запуск команд:
  інструменти, що потребують підтвердження, просто відхиляються. Дозволено лише
  `mcp__inbox` — усі його інструменти тільки читають (stats, chats, search, conversation,
  digest, sync); надсилати повідомлення він не вміє. Розпізнана мова буває неточною —
  не давайте широких прав.
- Оплата: `claude -p` працює в межах підписки (ті самі ліміти, що й інтерактивний
  Claude Code). Окремий рахунок можливий лише з `ANTHROPIC_API_KEY` (його `run.sh` прибирає)
  або якщо в акаунті ввімкнено платне використання понад ліміт.

## Налагодження

- `BRIDGE_ECHO=1` — відповідати «Ви сказали: …» без виклику Claude;
  `BRIDGE_ECHO_DELAY=9` — з такою штучною затримкою (секунд). Так перевірялися тайм-аути браслета.
- Перед whisper PCM нормалізується до піку −3 dBFS (підсилення до 30×): мікрофон браслета
  дуже тихий, і без цього whisper вигадує текст.

## Перевірено

- `/text`: відповідь за ~9 с, київський час правильний, контекст між запитами зберігається.
- `/voice` з синтезованою українською фразою (`say -v Lesya`): розпізнано коректно
  (одна дрібна помилка), відповідь Claude — коректна. Перший виклик whisper ~12 с
  (холодне завантаження моделі), далі ~2 с.
- З браслета (2026-11-16): «Котра година?» розпізнано точно; кінець фрази визначається
  ~1 с після мовлення; «луна» з затримкою 9 с і проміжним «Думаю…» показується на браслеті
  без помилки. «Яка зараз погода?» → відповідь Claude з погодою в Києві за ~10 с.
- Служба launchd + Haiku + inbox MCP: «Скільки в мене непрочитаних чатів?» → коректна
  відповідь за 8 с.
- `STT_LANGS=uk,en`: українську фразу, яку whisper визначив як `ru`, розпізнано як `uk`;
  англійську — як `en`.
